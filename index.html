      Info

      How it works

      LabLens reads your report on this device with PDF and OCR engines, pulls out each value, and compares it with the reference range printed on the report. Where none is printed, general age and sex ranges are used and labelled. Every value links to the line it was read from so you can check it.

      Not medical advice

      LabLens is for information only. It does not diagnose or recommend treatment. Text extraction can make mistakes, so check results against the original report and talk to a qualified healthcare professional.
